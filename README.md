# Sonic Game Godot

Juego 2D estilo Sonic desarrollado en Godot Engine.
Desarrollado por Luis Miguel López, Aaron Gomez y David Oliva.

## 📖 Documentación
Consulta la estructura completa y detalles del proyecto en [documentacion.md](./documentacion/documentacion.md).

## 📊 Presentación
Consulta la presentación del proyecto en [presentacionTonyc.pptx](./presentacion/presentacionTonyc.pptx).

## 🚀 Cómo ejecutar
1. Abre `proyecto.godot` en Godot 4.x
2. Presiona F5 para jugar

## 📁 Estructura rápida
- `jugador_sonic/`: Personaje principal y assets
- `enemigos/`: Enemigos y obstáculos
- `menus/`: Pantallas de menú y muerte
